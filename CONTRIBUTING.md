# Contributing

Bug reports and focused pull requests are welcome.

Before making a code change, follow the platform instructions in the
[development guide](docs/development.md). Add or update tests for observable
behaviour and run the complete test suite before submitting a pull request.

Keep changes focused and explain what changed, why it changed, and how it was
verified. Include screenshots for visible interface changes and mention any
platform or codec behaviour you could not test locally.

Only add media that you have the right to redistribute. Contributions are
licensed under the repository's [MIT License](LICENSE).
