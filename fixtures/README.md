# Regression video corpus

The committed media fixtures are base64-wrapped so they remain portable through source patches and text-oriented tooling. Native tests materialize them in the system temporary directory and remove them afterward.

| Fixture | Encoded properties | Regression purpose |
|---|---|---|
| `cfr_h264.mp4.b64` | H.264, 96x64, 12 fps, 12 frames, YUV 4:2:0 | Common CFR decoding and B-frame presentation order |
| `cfr_hevc.mp4.b64` | HEVC/hvc1, 96x64, 12 fps, 12 frames, YUV 4:2:0 | iPhone-compatible HEVC decoding |
| `rgb_ffv1.mkv.b64` | FFV1, 32x24, 4 fps, four frames, BGR0 | RGB analysis-conversion fallback |
| `vfr_timing.mov.b64` | H.264, 64x48, five VFR frames | Exact source PTS and bounded VFR parity oracle |
| `rotated_h264.mov.b64` | H.264, stored 96x64, 90-degree display matrix | Phone-style orientation metadata and displayed 64x96 output |
| `odd_h264.mp4.b64` | H.264 High 4:4:4, 95x63, seven frames | Odd-width and odd-height color conversion |
| `long_cfr_h264.mp4.b64` | H.264, 160x90, 30 fps, 300 frames | Cancellation against a nontrivial real decoder stream |
| `packed_yuyv422.avi.b64` | Raw YUYV 4:2:2, 32x24, one frame | Packed luma/chroma analysis-conversion fallback |
| `gray_alpha_ffv1.mkv.b64` | FFV1, 32x24, one interleaved gray/alpha frame | Interleaved gray/alpha analysis-conversion fallback |
| `planar_10bit_ffv1.mkv.b64` | FFV1, 32x24, one 10-bit planar YUV frame | Native high-bit-depth luma analysis conversion |
| `planar_12bit_ffv1.mkv.b64` | FFV1, 32x24, one 12-bit planar YUV frame | Native high-bit-depth luma analysis conversion |
| `planar_16bit_ffv1.mkv.b64` | FFV1, 32x24, one 16-bit planar YUV frame | Native high-bit-depth luma analysis conversion |

All imagery is generated from FFmpeg's synthetic test sources and contains no personal footage. The small clips are committed so CI does not need encoders, and so decoder behavior is tested against fixed bytes.

The long CFR fixture also freezes the Medium profile's selected frame sequence.
This catches unintended extraction changes while allowing diagnostic scores and
performance timings to vary between platforms.

## Regeneration

From the repository root:

```sh
./scripts/generate_regression_fixtures.sh
```

Regeneration requires `ffmpeg`, `python3`, `libx264`, and `libx265`. The script is byte-deterministic with the pinned local FFmpeg 8.0.1 toolchain. A different encoder version can produce different bytes while retaining the same semantic properties, so review fixture and decoder-test changes together.

The VFR timing oracle is intentionally not regenerated by this script because its exact PTS sequence is part of the frozen Python parity contract.
