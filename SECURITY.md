# Security policy

Please do not disclose suspected security vulnerabilities in a public issue.
Use GitHub's **Report a vulnerability** form on the repository's Security page
so the report and any discussion remain private.

Include the affected Frame Extractor version and platform, a concise description
of the impact, and reproduction steps when possible. Reports concerning the
latest release or the current `main` branch are in scope. Ordinary bugs and
feature requests should use the public issue tracker.
